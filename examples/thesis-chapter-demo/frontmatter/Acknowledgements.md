# Acknowledgements

This is fixture text. It thanks nobody real.

It exists so that the acknowledgements page has prose to set, and so that the
converter which joins wrapped lines into paragraphs has more than one line to
join. The people a real acknowledgements page would name are deliberately absent:
a demonstration image should carry no one's private words.

Any institution, supervisor or family member you might expect to see here is, by
design, not here.
